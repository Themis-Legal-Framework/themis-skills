# Exhibit and Attachment Plan (Pleadings)

## Inputs
- Draft pleading (or outline)
- List of key documents (contracts, notices, letters, records)
- User goals (credibility, specificity, early motion resistance, etc.)
- Jurisdiction/venue (optional)

## Outputs
1) Exhibit list proposal:
   - attach / reference only / omit for now
2) Paragraph cite map: exhibit → where referenced
3) Risk flags:
   - incorporation-by-reference risks
   - authenticity/foundation risks
   - unintended admissions
   - confidentiality/privacy risks
4) Open questions for the user

## Rules
- Jurisdictions vary on what should/shouldn't be attached; treat as conditional:
  - `[CHECK LOCAL PRACTICE: attaching contracts/notices]`
- Recommend attaching only when it advances a clear purpose and does not create avoidable problems.

## Common decision heuristics (jurisdiction-agnostic)
- Attach if: the document is central, undisputed, short, and strengthens plausibility.
- Don't attach if: it creates ambiguity, invites adverse interpretation, or raises authentication/confidentiality issues early.
